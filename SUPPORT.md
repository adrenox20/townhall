# Support

If you need help using, deploying, or developing **Townhall**, please review the following resources:

## 📖 Documentation

- **Getting Started**: Check the [README.md](README.md) for local development instructions.
- **Deployment**: See [DEPLOY.md](DEPLOY.md) for full instructions on deploying to Cloudflare.
- **Contributing**: Refer to [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines on how to submit code changes.

## 🐛 Bug Reports & 💡 Feature Requests

If you have found a bug or want to request a new feature, please search the [existing issues](https://github.com/adrenox20/townhall/issues) first.
If your issue is not listed, you can [open a new issue](https://github.com/adrenox20/townhall/issues/new/choose) using the provided templates.

## 🔒 Security

If you discover a security vulnerability, **do not open a public issue**. Please review our [Security Policy](SECURITY.md) for instructions on how to report it securely.
